# Conformance cases: what every implementation must print, byte for byte.
# The format is described in SPEC.md ("Conformance"). In short:
#
#   [mode] name          starts a case; mode is rich, plain or agent
#   % NAME=value         an environment variable for the case
#   $ function args      a call (shell quoting); several calls run in one process
#   < text               a line of standard input ("<" alone is an empty line)
#   |text                an expected line of standard output
#   !text                an expected line of standard error
#   = N                  the expected exit status of the last call (default 0)
#
# Escapes in input and expected lines: \e escape, \t tab, \r carriage return, \s space,
# \b backspace (the DEL character). In a call, \e is an escape character too.
# An expected line ending in \c has no newline after it.
# <T> stands for any duration (12ms, 4.2s, 3s).
# Every case runs with COLUMNS=80, LANG=en_US.UTF-8 and no terminal.
# The working directory is this one, so that "files" names the directory next to this file.
